# Alex Smith Portfolio

A responsive and modern personal portfolio website built using **HTML**, **CSS**, and **Bootstrap**.  
This project showcases portfolio sections such as About, Services, Projects, Testimonials, Blog, and Contact information with a clean and user-friendly interface.

---


---

## 📌 Features

- Responsive design for all screen sizes
- Modern landing page UI
- Smooth navigation between sections
- About and Services sections
- Portfolio gallery with hover effects
- Testimonials and Blog section
- Contact form layout
- Social media icons using Font Awesome
- Clean and organized code structure

---

## 🛠️ Built With

- HTML5
- CSS3
- Bootstrap
- Font Awesome
